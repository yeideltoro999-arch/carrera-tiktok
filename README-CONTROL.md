# Carrera TikTok — control para LIVE Studio

## Uso recomendado
1. Ejecuta `start-control.bat`.
2. Abre `http://127.0.0.1:3210/` para la carrera.
3. En TikTok LIVE Studio agrega una fuente de navegador con esa misma URL.
4. Abre `http://127.0.0.1:3210/control.html` en Chrome.
5. Desde ese panel pulsa iniciar, detener, reiniciar, regalos, likes o turbo.

El servidor no necesita npm ni paquetes externos.

La versión de GitHub Pages también sigue disponible, pero el control remoto local es el recomendado para LIVE Studio porque la carrera y el panel pasan por el mismo servidor local.

## Comandos
start, stop, reset, gift, like, turbo.
